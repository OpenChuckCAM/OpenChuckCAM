# Makera Z1 test record: 0.55.0-rc3 (A-limit fix)

Nov 14, 2026 · Paul H

## Start here

rc3 corrects the built-in Z1 profile to the behaviour measured on the machine in the 14 Nov 2026 tests and decisions. The main change: the A-axis limit goes from 3600 to 1800 deg/min, which the controller enforces (`M203.1` printed `A: 30`). Cutting positions do not change. What changes: F words and time estimates (A limit); the default safe Z is 45 instead of 40 on rapids and retracts; and profile values (travel, clearance, the rotary reference at the headstock face, spindle range), with the sample layouts shifted to match so G-code X words do not change. So most of rc2's gate 4 carries over, and the Z1 runs here are spot checks plus the checks that were never run.

Generated G-code is the user's to verify before it is run on a machine (NFR-12). Nothing in this record means a program is safe. Every program is read before it is run.

**Common conditions for every Z1 run in this record:** no tool and no material for Parts B and C; G54 set with A at WCS Y0 Z50 as for rc2 gate 4; feed override 100 %; enclosure closed; stop button in reach; phone video with sound for any timed run.
