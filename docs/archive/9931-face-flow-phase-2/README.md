# Decision 9931: face-flow finishing's phase 2 on the public blisk, screenshots

Cited by [decision record 9931](../../decisions/9931-face-flow-stays-down-follows-outlines-and-drops-short-cuts.md) (issue #854).

Both images are screenshots of the program itself, true captures with nothing drawn on them, from the release build of branch `claude/lane-faceflow` (the face-1 image at commit `239acd1a`, the face-7 image at `4694c963`; between them the code changes only by lint fixes with no change of behaviour, the wording of one refusal and tests, none of which changes these paths), Linux, Xvfb with Mesa's lavapipe software Vulkan, window 1920 x 1080. Each shows two captures with the same view: above, "before" (Pattern Along the guide, Stay down between passes off, Steps between rings Sharp, Shortest cut 0: today's program, which a saved operation keeps); below, "after" (what a new operation gets: Automatic, Stay down on, Blended, Shortest cut Tool diameter). They were taken on copies of the public reference project `testdata/projects/face_flow` (`testdata/step/valid/blisk.step`, 3 mm ball) with a 1 mm stepover and the face set changed as each line says; no private project was used. Colours: orange cuts, green links, lilac entries, hatching unreached.

- [face1-outside-before-after.png](face1-outside-before-after.png): face 1, the outside face (the rim and every blade's tip), which closes round on itself. Before: 52 rings, broken at every blade, each piece entered and left (298 rapid moves in the LinuxCNC program). After: Automatic follows the face's outline, round the rim and along each blade's tip, inwards at the stepover, with the tool staying down between passes (11 rapid moves).
- [face7-blade-before-after.png](face7-blade-before-after.png): face 7, a blade, seen from below so its face is towards the camera (the Front view of the face-1 image, then turned about the part's axis by a drag of 200 pixels in the viewport, about 80 degrees; the same view for both), the viewport cropped round the blade; before on the left, after on the right. The blade is cut along its tip edge (a plain face: Automatic keeps the guide). Before: an entry at the start of every pass (the lilac lines at the blade's end). After: the passes are joined at the blade's end by steps along the face (7 rapid moves against 12); it lifts at the X 20 end, where the rim is in the way. Re-captured on 24 Nov 2026 at the owner's request, from the release build of commit `4694c963` (the same code as the face-1 image), replacing a front view in which the blade's paths were seen edge-on.

The images are reduced to 256 colours to keep the files small. The driver was a scratch copy of `user-docs/tools/capture_example.py` (open the project, front view as the guide's blisk examples set it, Generate stale, for face 7 a drag in the viewport to turn the view, capture), not kept; the face-1 image is the front view with the viewport cropped, before above and after below.
