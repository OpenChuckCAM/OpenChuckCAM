# Getting support

Support for OpenChuckCAM is best effort. The maintainer answers when time allows; there is no promised reply time.

- **Questions, machine and post help, ideas, and showing what you made:** [GitHub Discussions](https://github.com/OpenChuckCAM/OpenChuckCAM/discussions). Start with the [Q&A](https://github.com/OpenChuckCAM/OpenChuckCAM/discussions/categories/q-a) category, or [Machines & Post Processors](https://github.com/OpenChuckCAM/OpenChuckCAM/discussions/categories/machines-post-processors) for a machine or a post.
- **Bugs and feature requests:** [GitHub issues](https://github.com/OpenChuckCAM/OpenChuckCAM/issues/new/choose). See [Reporting a problem or asking for a feature](https://openchuck.cam/latest/reporting.html) for what to include.
- **Security problems and code of conduct reports:** email github@openchuck.cam. Do not post them in public.

Look in the [user guide](https://openchuck.cam/latest/), [Troubleshooting](https://openchuck.cam/latest/troubleshooting.html) and [Known limitations](https://openchuck.cam/latest/start/limitations.html) first. Issues and discussions are public: do not post a project or model you do not want to share.

Generated G-code is yours to verify before you run it on a machine (NFR-12). OpenChuckCAM does not guarantee that a program is safe or correct. If G-code looks wrong or unsafe, do not run it.
